# Rules MOC

Use this MOC to track house rules, rulings, system assumptions, mechanics observed in play, and logging conventions.

## Logging Conventions

- Partylog notation is the preferred format for parsed session logs.
- Session notation should use `@(...)` for actions, `!` for world events, `d:` for rolls, and `=>` for consequences.
- Digital session notes should wrap Partylog notation in markdown code fences.

## Observed Mechanics

- d20 investigation checks.
- d20 deception checks.
- d20 perception checks.
- Dexterity saving throws.
- Wisdom saving throws.
- Attack rolls.
- Damage rolls.
- Hit point loss.
- Spellcasting and class features.
